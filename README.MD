# Матемагия 🧮

**Матемагия** — это тренажёр устного счёта. Помогает развивать скорость и точность арифметических вычислений. Никакой магии — только регулярная практика и результат.

## 📱 Играть

Приложение доступно во ВКонтакте:

[**🎮 Играть в Матемагию**](https://vk.ru/app51937586)

## ✨ Возможности

- Сложение, вычитание, умножение, деление
- Короткие тренировки — всего 5–10 минут в день
- Подходит для школьников и взрослых

## 🛠 Технологии

Проект реализован как VK Mini App.

Игра работает directly во ВКонтакте — установка не требуется.  
Просто перейдите по ссылке и начните тренировку:
